Features

Simple to start. Deep when you need it.

Everything you reach for every day is one click or one shortcut away — and nothing is in your way until you ask for it.

⚡

Instant large files

Huge logs and data dumps open instantly in a smooth, virtualized viewer instead of freezing the app.

✨

AI autocomplete

Ghost-text suggestions as you type. Press Tab to accept, Esc to ignore. Plus an AI chat for questions about your code.

▶️

A terminal that runs code

Not a toy: run app.js executes JavaScript, python file.py runs real Python, and you get cd, ls, grep, history and tab-completion.

🗂️

Real folders, real files

Open any folder on your computer. Saves go straight to disk, renames and deletes are real, and your last folder reopens automatically.

🪟

Split panes

Up to four editors side by side or stacked, each with its own file, with draggable dividers.

🔎

Find anything fast

Ctrl+K jumps to any file by name, Ctrl+F finds and replaces, and project-wide search covers every file.

🧠

Writes code with you

Auto-closing brackets and quotes, smart indent, bracket matching, one-key comment toggle, and multi-line indent.

🩺

Catches mistakes early

Squiggly underlines for errors and warnings with an AI quick-fix — hover to read, click to fix.

🌐

Live HTML preview

Build a web page across HTML, CSS and JS files and preview it in one click, updating as you type.

Built for big files

Open a 64 MB file.
Feel nothing.

Most editors try to colour and number every line of a file at once. X Code only draws what's on your screen, so file size stops mattering for opening and scrolling.

Measured in our own tests (Chromium, synthetic JavaScript files). Files over 2 MB open in a fast read-only view with go-to-line; press Edit anyway to edit them (typing in multi-megabyte files is limited by the platform's text box, so it can feel slower). Real-world speed depends on your machine.

How to use it

Learn it in a minute.

Three things to know. Everything else you'll discover as you go.

Your first five minutes

  1. Open Folder (top bar, or Ctrl+O) and pick a project. Or press Try a sample project on the welcome screen.
  2. Click a file in the sidebar to edit it. Saves are automatic to your session; Ctrl+S writes to disk.
  3. Press ▶ in the top bar to preview an HTML page, or open the terminal with Ctrl+` and type run app.js.
  4. Stuck? Type help in the terminal, or open the AI chat from the left bar.
